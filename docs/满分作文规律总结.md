# 高考满分作文规律总结

> 本文件是对实验提供的 20 篇历年高考满分范文样例进行归纳后的结论，
> 是设计核心提示词（见 `app/prompt.py`）的依据。

## 一、标题规律

- **精炼凝练**：多为 2～8 字，短小有力，如《蝶变》《给感情一把尺》《赤兔马之死》。
- **富有文采**：善用比喻、对偶、化用古诗词、设置悬念等手法。
- **紧扣立意**：标题即是文章灵魂，与正文主旨高度统一。

## 二、开头规律（先声夺人）

- 多用**排比**营造气势：如“无论何时……无论何地……无论……”。
- 多用**比喻**引出意象，或以**设问/反问**引人深思。
- 常用**名言、诗词、典故**开篇，彰显文化积淀。
- 篇幅约 50～120 字，迅速点题、亮出观点。

## 三、结构规律（层次分明）

- 主体普遍设置 **3 个左右分论点**，层层递进，结构清晰。
- 分论点句**句式整齐**、独立成段或置于段首。
- 采用“**提出观点 → 事例论证 → 回扣观点**”的经典论证结构。

## 四、论据 / 素材规律（古今中外结合）

- **古代先贤**：唐太宗、林则徐、司马迁等。
- **革命先辈 / 时代楷模**：长征精神、白衣天使、时代先锋等。
- **中外文化名家**：伽利略、贝多芬、爱默生等。
- 善用**名言警句、诗词典故**增强说服力。

## 五、语言规律（文白相济、凝练典雅）

- 文白夹杂，善用**排比、对偶、比喻、引用、反问**等修辞。
- 句式**长短错落**，富有节奏感与音乐美。
- 避免空洞口号，追求**真情实感与思辨深度**。

## 六、立意规律（高远深刻）

- 紧扣题目，立意高远，常见主题有：**家国情怀、理想信念、时代担当、文化传承、人生哲思**。
- 关注个人成长与社会、时代、传统的关系，具有思辨性。

## 七、结尾规律（升华收束）

- 篇幅约 60～100 字，**升华主题、呼应开头与标题**。
- 语言有感染力、有哲理，常发出号召或留下隽永余味。

## 八、格式规律

- 全文 **800 字左右**（750～900 字）。
- 段落分明、标点规范，标题与正文清晰分开。
